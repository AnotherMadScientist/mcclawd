# Phase 4: State Persistence, OpenClaw Compat, Provider Pool, ClawHub Import

> **For Claude:** Use subagent-driven development with parallel execution.

**Goal:** Add channel state persistence (save_state/restore_state + encrypted storage), OpenClaw config compatibility (openclaw.json + .mcp.json import), provider pool with budget controls + hot-reload config, HashiCorp Vault secret backend, and ClawHub registry skill import.

**Architecture:** Four independent workstreams executed in parallel. Each builds on existing traits and infrastructure with minimal cross-stream dependencies.

---

### Task A2: ChannelStateStore — encrypted file-backed state storage

**Files:**
- Create `crates/mcclawd-channels/src/state_store.rs`
- Modify `crates/mcclawd-channels/src/lib.rs` (export)

Implement `ChannelStateStore`:
```rust
#[async_trait]
pub trait ChannelStateStore: Send + Sync {
    async fn save(&self, channel_kind: &str, state: Vec<u8>) -> anyhow::Result<()>;
    async fn load(&self, channel_kind: &str) -> anyhow::Result<Option<Vec<u8>>>;
    async fn delete(&self, channel_kind: &str) -> anyhow::Result<()>;
    async fn list(&self) -> anyhow::Result<Vec<String>>;
}
```

Two implementations:
1. `InMemoryStateStore` — DashMap-backed for testing
2. `FileStateStore` — stores state files at `{data_dir}/channel_state/{channel_kind}.bin`
   - Each file is AES-256-GCM-SIV encrypted using the same vault key as secrets
   - Uses `mcclawd_core::secrets` encryption utilities (aes-gcm-siv + argon2)
   - Atomic writes via temp file + rename

Tests: save/load roundtrip, missing key returns None, delete removes, list returns keys, encryption works.

```rust
pub struct ConfigWatcher {
    config_path: PathBuf,
    tx: watch::Sender<McclawdConfig>,
    rx: watch::Receiver<McclawdConfig>,
}

impl ConfigWatcher {
    pub fn new(config_path: PathBuf) -> Result<Self>;
    pub fn subscribe(&self) -> watch::Receiver<McclawdConfig>;
    pub async fn watch(&self, shutdown: CancellationToken) -> Result<()>;
```

```rust
pub struct SkillInstaller {
```
